# Discord Clone - Symfony

Application de messagerie instantanée inspirée de Discord, développée dans le cadre du module Symfony (DEVE302).

## Fonctionnalités
- **Gestion des utilisateurs** : Inscription, connexion sécurisée et déconnexion.
- **Gestion des salons (Channels)** : Création, modification, suppression et affichage des salons de discussion.
- **Messagerie** : Envoi et consultation de messages en temps réel au sein de chaque salon, associés aux utilisateurs connectés.

## Prérequis
- PHP 8.2+
- Composer
- MySQL / MariaDB
